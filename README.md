# Entwurf: neue Website für ein Gästehaus in Garmisch-Partenkirchen

Privater Prototyp, als Dankeschön für die Gastgeber gebaut. **Das ist nicht der offizielle
Auftritt des Gästehauses.**

- Vorschau: https://rishavsinghi93.github.io/gaestehaus-entwurf/ (Deutsch, mit Umschalter auf Englisch)
- Statisches HTML, CSS und JavaScript, ohne Build-Schritt.
- Die Fotos liegen nicht in diesem Repository. Sie werden von der bestehenden Website geladen und
  bleiben © der jeweiligen Rechteinhaber (siehe Impressum der Seite).
- Das Anfrageformular ist eine Attrappe und verschickt nichts.

---

Private prototype of a new website for a guesthouse in Garmisch-Partenkirchen, made as a thank-you
for the hosts. **Not the guesthouse's official website.** Photos are loaded from the existing site
and remain © their owners; the booking form doesn't send anything.
